# 📊 Customer Churn Analysis & Prediction

An end-to-end Data Science project focused on analyzing customer behavior and predicting customer churn using exploratory data analysis, data visualization, and machine learning.

## 🎯 Project Overview

Customer churn is a major challenge for businesses that rely on recurring customers.

The goal of this project is to:

- Understand the factors associated with customer churn
- Explore customer behavior through data analysis
- Identify important patterns and trends
- Build a machine learning model to predict customer churn
- Evaluate model performance
- Generate actionable business insights

## 🧠 Key Questions

- What factors are strongly associated with customer churn?
- Which customer segments have the highest churn rate?
- Does customer tenure affect churn?
- How do contract types influence churn?
- Can machine learning accurately predict customers who are likely to churn?
